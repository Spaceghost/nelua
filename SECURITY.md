# Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/Spaceghost/nelua/security/advisories/new)
for a suspected vulnerability in this repository. Include the affected commit or
`nelua -v` output, platform, compiler, impact, and any reproduction steps you can
share privately. Use [GitHub issues](https://github.com/Spaceghost/nelua/issues) for
ordinary bugs and [upstream Nelua](https://github.com/edubart/nelua-lang) for
issues specific to the upstream project.
